一. 知识储备

1.漏洞介绍

文件上传漏洞是指用户上传了一个可执行的脚本文件，并通过此脚本文件获取了执行服务器端命令的能力，这种攻击方式是最直接和有效的，文件上传本身是没有问题的，有问题的是文件上传后，服务器怎么处理，解析文件。通过服务器的处理逻辑做的不够安全，则会导致上传漏洞。

2.漏洞条件

  • 文件可上传
  • 知道文件上传漏洞
  • 上传文件可以被访问
  • 上传文件可以被执行

3.相关函数

下面介绍一些文件上传漏洞相关的函数：

  • move_uploaded_file(file,newloc):函数将上传的文件移动到新的位置。
  • strolower():函数把字符串转换为小写。
  • trim():函数移除字符串两侧的空白字符或其他预定义字符。
  • strrchr():函数查找字符串在另一个字符串中最后一次出现的位置，并返回从该位置到字符串结尾的所有字符。
  • srt_ireplace():函数替换字符串中的一些字符(不区分大小写)。
  • getimagesize():函数用于获取图像大小及相关信息，成功返回一个数组，失败则返回FALSE并产生一条E_WARNING的错误信息。
  • exif_imagetype():读取一个图像的第一个字节并检查其签名。
  • substr():函数返回字符串的一部分。
  • fopen():函数打卡文件或URL。
  • fread():函数读取文件(可安全用于二进制文件)。
  • fwrite():函数写入文件(可安全用于二进制文件)。

可以很明显的看到，上传前后图片大小出现了很明显的变化。

for ($y = 0; $y < sizeof($p); $y += 3) {

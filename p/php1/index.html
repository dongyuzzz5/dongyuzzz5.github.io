一. PHP简介

1.什么是PHP

  • PHP 是 “PHP: Hypertext Preprocessor” 的缩写（超文本预处理器）
  • PHP 是一种广泛使用的开源脚本语言
  • PHP 脚本在服务器上执行

2.PHP能做什么

  • PHP 可以生成动态页面内容
  • PHP 可以在服务器上创建、打开、读取、写入、删除和关闭文件
  • PHP 可以收集表单数据
  • PHP 可以发送和接收 cookie
  • PHP 可以在数据库中添加、删除、修改数据
  • PHP 可用于控制用户访问
  • PHP 可以加密数据

三. 变量

1.变量的命名规则

变量以 $ 符号开头，后跟变量名变量名
必须以字母或下划线字符开头
变量名不能以数字开头
变量名只能包含字母数字字符和下划线（A−z、0−9 和 _ ）
变量名区分大小写（$age 和 $AGE 是两个不同的变量）

1
2

$x = 5;
$y = "Bill"

在上面的例子中，变量 $x 将保存值 5，变量 $y 将保存值 “Bill”。
注意：当文本值分配给变量时，请将值放在引号中。

PHP 有三种不同的变量作用域：

(2) global（全局）—— 客厅
定义：在函数外面定义的变量，整个PHP文件都能用，但在函数里使用需要特别声明。

四. echo 和 print 语句

1.区别

echo 和 print 或多或少是相同的。它们都用于将数据输出到屏幕。
它们之间的区别很小：echo 没有返回值，而 print 的返回值为 1，因此它可以在表达式中使用。echo 可以接受多个参数（尽管这种用法很少见），而 print 只可接受一个参数。echo 比 print 略快一些。

2.基本用法

echo 语句可以带括号使用，也可以不带括号使用：echo 或 echo()
同理，print语句也是一样的

1.获取数据类型

PHP 支持以下数据类型：

  • 布尔值（Boolean）

2.简单介绍

  • 字符串： 字符串是由字符组成的序列。字符串可以是引号内的任何文本。可以使用单引号或双引号。
  • 整数： 整数数据类型是非小数的数，范围在 -2,147,483,648 到 2,147,483,647 之间。
  • 浮点数： 浮点数（floating point number）是带有小数点的数字或以指数形式表示的数字。
  • 布尔值： 布尔值表示两种可能的状态：TRUE 或 FALSE。
  • 数组： 数组在单个变量中存储多个值。
  • NULL值： 一种特殊的数据类型，它只有一个值：NULL。如果变量已创建但未赋值，它将自动被赋值为 NULL。也可以通过将值设置为 NULL 来清空变量。
  • 对象： 类和对象是面向对象编程的两个主要方面。类是对象的模板，而对象是类的实例。

3.对象

理解前先引入菜鸟网站里面的解释

当创建各个对象时，它们从类中继承所有的属性和行为，但每个对象将为属性设置不同的值。
假设我们有一个名为 Car 的类，该类可拥有模型、颜色等属性。我们可以定义变量，如 $model、$color 等，以保存这些属性的值。
当创建各个对象（Volvo、BMW、Audi 等）时，它们从类中继承所有的属性和行为，但每个对象将为属性设置不同的值。
如果您创建一个 __construct() 函数，当您从类创建对象时，PHP 将自动调用此函数。

现在用一个"做饼干"的比喻，方便理解上面的解释：
(1) 类是模具，对象是饼干 🍪

 1

// 这是一个"类"（Class）= 饼干模具
class Car {
    public $color;   // 颜色属性
    public $model;   // 型号属性
}

// 下面这是"对象"（Object）= 用模具压出来的具体饼干
$volvo = new Car();   // 第一块饼干：沃尔沃
$bmw = new Car();     // 第二块饼干：宝马  
$audi = new Car();    // 第三块饼干：奥迪

关键理解：

  • 类（Car）只是一张设计图纸，它规定了"汽车应该有颜色和型号"，但它本身不是车
  • 对象（volvo, bmw）是真正的车，是根据图纸造出来的实物

(2) 每个对象有自己的"个性" 🎨
虽然都是用同一个 Car 模具做的，但每辆车可以刷不同的颜色：

$audi->color = "红色";   // 奥迪是红色的

echo $volvo->color;  // 输出：白色
echo $bmw->color;    // 输出：黑色

就像：同一个饼干模具（类）,但可以做出巧克力味、草莓味、抹茶味的饼干（对象属性值不同）

(3) __construct() 是"出厂设置" ⚙️

2.PHP整数

定义：整数是没有任何小数部分的数字。在 32 位系统中，整数数据类型是在 -2147483648 和 2147483647 之间的非小数数，在 64 位系统中，是在 -9223372036854775808 和 9223372036854775807 之间的非小数制数。大于（或小于）此范围的值将存储为浮点数，因为它超过了整数的限制。2, 256, -256, 10358, -179567 都是整数。
注意：另一件需要知道的重要事情是，即使 4 * 2.5 等于 10，结果为浮点数，不为整数。
PHP 有以下预定义的整数常量：

  • PHP_INT_MAX - 支持的最大整数
  • PHP_INT_MIN - 支持的最小整数
  • PHP_INT_SIZE - 整数的大小（以字节为单位）

3.PHP 浮点数

定义：浮点数是具有小数点或以指数形式表示的数字。浮点数数据类型通常可以存储高达 1.7976931348623E+308 的值（取决于平台），并且具有最大14位数的精度。2.0, 256.4, 10.358, 7.64E+5, 5.56E-5 都是浮点数。
PHP 有以下预定义的浮点数常量（从 PHP 7.2 开始）：

  • PHP_FLOAT_MAX - 可表示的最大浮点数
  • PHP_FLOAT_MIN - 可表示的最小正浮点数
  • PHP_FLOAT_DIG - 可以四舍五入为浮点数并返回而不损失精度的十进制数字的数量
  • PHP_FLOAT_EPSILON - 可表示的最小正数 x，使得 x + 1.0 != 1.0

可以用is_float()函数来检查变量的类型是否为浮点数。

1
2

一. Hugo 博客搭建

1. Hugo 下载

(1) 进入Hugo官方网站：https://gohugo.io/
     左上角选择Github

(2) 点击 Releases 发行版，进入历史仓库
     并选择最新版本，示例：hugo_extended_xxxxx_windows_amd64.zip

(3) 本机为windows版本，我这里选的是 hugo_extended_0.154.5_windows-amd64.zip

(4) 下载压缩包到任意文件夹后，解压。 (建议放到除c盘外的其他盘，我这里因为是演示所以直接放桌面了)

2. 创建博客

(1) 在文件命令行输入 cmd 进入命令行窗口，输入命令：

1

hugo new site dongyu2   # 这里的 dongyu2 是自定义的文件夹名称

(2) 接着切换目录到刚刚新建的文件夹 dongyu2：

1

cd dongyu2

(3) 打开刚刚的文件夹可以看到新建的 dongyu2 文件夹。
      由于没有配置全局环境变量，因此要复制 hugo.exe 到 dongyu2 文件夹中才能运行。

(4) 在命令行中输入下面命令，启动 hugo

1

hugo server -D

正常来说下方红框显示的窗口应该是1313，不过我这里启动了两个hugo,所以不一样

(5) 接着在浏览器上访问，跳转出的 web 页面如下，说明创建成功（没有内容属于正常情况）:

二. Stack 主题配置

1. 重要说明

 > 官方提供可以选的主题有很多，且由于每个主题的开发者实现的功能不同，因此建议根据下载的主题的 Github 上的 Readme.md 文件中的操作一步步来进行配置。
 > 我这里选择的是和我博客一样相同的主题stack进行演示，若不想和我一样可以去网上直接搜其他主题的配置方法或查看官方文档
 > 若和我选择的主题不一样，可以直接跳到第四点看自动化部署 (也可以参考一下，因为主题配置的步骤都大差不差，就美化不一样而已)

2. 下载主题

(1) 回到Hugo官方主页面，点击 Themes

(2) 选择stack主题

(3) 点击Download进行下载，也可以先选择Demo进行预览

(4) 跳转到 GitHub 页面，然后点击 Releases

(5) 当前版本为 v3.33.0，下拉找到 Assets，点击 Source code（zip）下载

(6) 将下载好的压缩包复制或剪切到之前创建的 dongyu2 文件夹中的 theme 目录中，并解压到当前目录同名文件夹

3. 配置主题

(1) 来到主题目录下，点击exampleSitew文件夹(一般主题都有这个样例文件夹，没有的查看官方文档)       接着着将文件夹中的content文件夹和hugo.yaml文件复制到dongyu2主目录下面
      并将dongyu2文件夹中的hugo.toml删除

(2) 将/content/post下的rich-contnet文件夹删除里面引用了youtube的一些视频可能会导致网站启动不了 (有些主题可能没有这个文件夹，跳过即可)

(3) 然后我们打开配置文件/hugo.yaml，可以看到theme名称是没有版本号的，所以我们要将主题文件夹名称的版本号删除，不然到时候会显示找不到文件夹

(4) 输入命令重启hugo服务，再刷新网页，就会发现网站已经搭建完成

1

hugo server -D

四. Github部署

1. 环境准备(Git)

(1) 进入Git官网:https://git-scm.com/ ,下载并安装最新版Git

(2) 选择 Git for Windows/x64 Setup进行下载，选择文件夹一直下一步安装就行了

2. 常规部署

(1) 进入Github官网:https://github.com/ ,创建一个Github账户

(2) 创建仓库，仓库名为： {自定义名称}.github.io (需严格按照格式，自定义名称建议用Github用户名)
      我这里因为已经用用户名创建过了，所以创建的是在子路径下

(3) 修改文件路径 (非常重要，后面若网页显示错误，大概是这里的url错了)

  • 打开文件hugo.yaml ,修改baseurl为仓库名的网址(第一次创建的话应该是没有我/dongyu2这个子路径的)

(4) 删除public文件夹，再重新启动hugo，生成新的public文件夹

1

hugo server -D

(5) 在新生成的public文件夹下进入cmd,输入下面命令，第一次上传可能需要输入账号密码,执行最后一步git push时如果不成功，多试几次，或者换个网络多试几次，有点玄学的

1
2
3
4
5
6

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin {你的github仓库地址}
git push -u origin main

也就是他网页给的那些命令

(6) 上传成功

(7) 前往 Setting -> Pages -> Branch选择main分支，然后保存，会自动开启

(8) 等待一段时间后刷新仓库，直到出现网址，就说明创建成功了，可以浏览该网址看到你的博客

3. 自动部署

(1) 创建一个新仓库，用于存放hugo主文件，记得设置为私有仓库

(2) 在hugo主目录下创建文件.gitignore

并在文件中写入下面内容(不需上传的文件)

1
2
3
4

public
resources
.hugo_build.lock
hugo.exe

(3) 接着在主目录下打开cmd,和刚刚一样输入创建仓库后生成的代码，不过第二句要改为 git add .

(4) 前往 Setttings -> Developer Settings -> Personal access tokens ，创建一个token(classic)

(5) token选择永不过期，并勾选 repo 和 workflow 选项

(6) 将生成的token，保存的仓库的变量中，前往 Settings -> Secrets and variables -> Actions 中设置
-注意：这里的token只会显示一次，刷新页面后就无了，记得保存

(7) 在hugo主文件创建一个.github/workflows/xxxx.yaml文件，将以下内容复制进去(代码中有一处要换成自己的token名和仓库名，不要一通复制了)

name: deploy

# 代码提交到main分支时触发github action
on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
        - name: Checkout
          uses: actions/checkout@v4
          with:
              fetch-depth: 0

        - name: Setup Hugo
          uses: peaceiris/actions-hugo@v3
          with:
              hugo-version: "latest"
              extended: true

        - name: Build Web
          run: hugo -D

        - name: Deploy Web
          uses: peaceiris/actions-gh-pages@v4
          with:
              PERSONAL_TOKEN: ${{ secrets.你的token变量名 }}
              EXTERNAL_REPOSITORY: 你的github名/你的仓库名
              PUBLISH_BRANCH: main
              PUBLISH_DIR: ./public
              commit_message: auto deploy

(8) 这样就算部署成功了，之后提交新的静态文件，只需要在hugo主目录下的cmd执行下面代码提交即可

git add .
git commit -m "update"
git push

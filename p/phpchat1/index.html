一. XSS介绍及原理

1.漏洞介绍

XSS漏洞通常指的是通过利用网页开发时留下的漏洞，通过巧妙的方法注入恶意指令代码到网页，使用户加载并执行攻击者恶意制造的网页程序。 这些恶意网页程序通常是JavaScript,但实际上可以包括Java、ActiveX、VBScript、Flash或者甚至是普通的HTML。攻击成功后，攻击者可能得到 但不限于更高的权限、私密网页内容、会话和cookie等各种内容。

2.漏洞原理

HTML是一种超文本标记语言，通过将一些字符特殊地对待来区别文本和标记，例如，小于符号(<)被看作是HTML标签的开始。当动态页面中插入的内容含有这些特殊符号时，用户浏览器会将其误认为 是插入了HTML标签，当这些HTML标签引入一段JavaScript脚本时，这些脚本程序就将会在用户浏览器中执行。所以，当这些特殊字符不能别动态页面 检查或检查出现错误时，就将会产生XSS漏洞。

3.XSS演示

下面通过两个例子加深一下对XSS漏洞的理解。
第一个：https://xss-game.appspot.com/level1
进去后我们可以看到一个输入框，我们在输入框中随便输入一点东西后点确认，我们可以看到页面返回了我们刚刚输入的内容。
这就说明该页面可能存在XSS漏洞。

所以我们尝试一下下面这句简单的payload。将它输入到刚刚的输入框中。

1

<script>alert(1)</script>

按回车后，可以看到网页弹出了内容为1的弹出，说明已经注入成功了。

我们通过F12开发者工具，可以查看到该语句确实已经插入到网页中。

接着我们来看第二个例子：https://xss-game.appspot.com/level2
我们尝试一下用刚刚的payload注入。

1

hello dongyu<script>alert(1)</script>

发现不起作用。
说明可能代码将<script>标签给过滤掉了。

我们可以尝试下另外一句简单的payload。

1

<img src=1 onerror=javascript:alert(1)>

可以看到页面出现了弹窗，说明注入成功了。

我们可以用开发者工具进行查看。

二. XSS漏洞种类

1.反射型XSS

简介：如果URL地址当中的恶意参数会直接被输出到页面中，导致攻击代码被触发，就称之为反射型XSS。

我们可以看到该字段是通过Get提交的，而且没有用双引号做包围。

所以我们可以直接在网址处通过Get提交，注入payload。

按下回车，网页回显"1"。

说明注入成功了，我们也可以通过开发者工具查看到。

<?php

// Is there any input?
if ( array_key_exists( "default", $_GET ) && !is_null ($_GET[ 'default' ]) ) {

	# White list the allowable languages
	switch ($_GET['default']) {
		case "French":
		case "English":
		case "German":
		case "Spanish":
			# ok
			break;
		default:
			header ("location: ?default=English");
			exit;
	}
}

?>

通过代码我们可以知道若是提交的不是四个选项中的一个，default都会返回为English。
那我们该如何如果呢。
这里就需要用到一个特性，我们在URL后面的#（卯）后面添加煜句的话，网页会直接读取为English,还会将#后面的语句也一起写入数据库中，这就造成了漏洞。

而这同时也说明了，DOM型XSS漏洞分为 反射型DOM型XSS漏洞 和 储存型DOM型XSS漏洞。

三. XSS的利用

1.介绍

1.窃取用户cookie(最常见): 当cookie没有设置HttpOnly属性时，可以通过javascript代码创建img、script、iframe等标签。并把src 属性设置为自己部署的xss cookie接收平台，以拼接document.xookie的形式把浏览页面的用户的cookie传递给自己。

2.界面劫持/伪造页面:
攻击者可以构造html/css/javascript代码。制作出一个与原网站风格相似的登录界面，或者把一些html元素移动/覆盖/遮挡,或利用javascript 的特性，重新定义页面的函数和变量，使原来的功能被篡改。

3.重定向页面:
一帮用于导流量，常见于黑产给菠菜网站导流。

4.CC攻击、获取敏感信息、结合CSRF漏洞等等。

2.实操

这里主要是要介绍一个XSS安全检测平台：https://xssaq.com/
打开后，先创建一个项目。模块选择默认模块，然后直接点击创建。

在创建的项目那里点击查看配置代码。

选择一句payload。

来到有XSS漏洞的平台，输入刚刚的payload。

提交后等一会，再回到我们刚刚的检测平台，发现已经有数据包返回。
说明入侵成功了。

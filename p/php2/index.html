2.防XSS漏洞

在上面代码中我们想要特别注意下面这一段

1
2


<form method="post" action="<?php echo htmlspecialchars($_SERVER["PHP_SELF"]);?>">

其中

  • $_SERVER[“PHP_SELF”] 变量 :是一个超全局变量，返回当前执行脚本的文件名。将提交的表单数据发送回自身页面，而不是跳转到另一个页面。这样，用户将在与表单相同的页面上收到错误消息。
  • htmlspecialchars() 函数 :将特殊字符转换为 HTML 实体。

这里想要用到htmlspecialchars() 函数是因为$_SERVER[“PHP_SELF”] 变量可能被黑客利用，进行XSS攻击。
假设我们在名为 “test_form.php” 的页面中有以下表单：

1
2


<form method="post" action="<?php echo $_SERVER["PHP_SELF"];?>">

如果用户在地址栏中输入正常的 URL，如 “http://www.example.com/test_form.php"，则上述代码将被翻译为：

1
2


<form method="post" action="test_form.php">

但是如果用户在地址栏中输入以下 URL：

1
2


http://www.example.com/test_form.php/%22%3E%3Cscript%3Ealert('hacked')%3C/script%3E

上述代码将被翻译为：

1
2


<form method="post" action="test_form.php/"><script>alert('hacked')</script>

此代码添加了一个脚本标签和一个 alert 命令。不过这是一个无害命令，只用来演示，若是黑客就会在此处植入木马。
为了避免该漏洞的产生，就想要用到htmlspecialchars() 函数了。
该函数将特殊字符转换为HTML实体，上面的代码就会被翻译成下面结果。

1
2


<form method="post" action="test_form.php/&quot;&gt;&lt;script&gt;alert('hacked')&lt;/script&gt;">

<?php
// 定义变量并设置为空值
$name = $email = $gender = $comment = $website = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $name = test_input($_POST["name"]);
  $email = test_input($_POST["email"]);
  $website = test_input($_POST["website"]);
  $comment = test_input($_POST["comment"]);
  $gender = test_input($_POST["gender"]);
}

function test_input($data) {
  $data = trim($data);
  $data = stripslashes($data);
  $data = htmlspecialchars($data);
  return $data;
}
?>
  • trim() 函数: 从用户输入数据中删除不必要的字符（额外的空格、制表符、换行符）
  • stripslashes() 函数: 从用户输入数据中删除反斜杠 \
  • test_input() 函数: 自定义函数，用于检查每个 $_POST 变量

四. 验证电子邮件和 URL

1.验证电子邮件

检查电子邮件地址格式是否正确的最简单、最安全的方法是使用 PHP 的 filter_var() 函数。
在下面的代码中，如果电子邮件地址格式不正确，则存储一条错误消息：

1
2
3
4

$email = test_input($_POST["email"]);
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
  $emailErr = "无效电子邮件";
}

2.验证URL

下面的代码展示了用preg_match() 函数来检查 URL 地址的语法是否有效（也可以用该函数来验证姓名）。如果 URL 地址的语法无效，则存储一条错误消息：

//验证URL
$website = test_input($_POST["website"]);
if (!preg_match("/\b(?:(?:https?|ftp):\/\/|www\.)[-a-z0-9+&@#\/%?=~_|!:,.;]*[-a-z0-9+&@#\/%=~_|]/i",$website)) {
  $websiteErr = "无效的 URL";
}

//验证姓名
$name = test_input($_POST["name"]);
if (!preg_match("/^[a-zA-Z-' ]*$/",$name)) {
  $nameErr = "只允许字母和空格";
}
